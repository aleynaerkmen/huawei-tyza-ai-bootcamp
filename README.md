# 🚀 Huawei Turkey AI Academy - Yapay Zeka Bootcamp

Bu repository, **Huawei Turkey AI Academy** bünyesinde Kaan Can Yılmaz eğitmenliğinde gerçekleştirilen Yapay Zeka Bootcamp programı süresince aldığım ders notlarını, kod örneklerini ve çalışmaları içermektedir.

## 📚 Müfredat ve İlerleme

| Modül | İçerik / Odak Noktaları | Durum |
| :--- | :--- | :---: |
| **1. Yapay Zeka için Python** | Python Temelleri, NumPy, Pandas | `✅ Tamamlandı` |
| **2. Veri Bilimi** | Veri Temizleme, Öznitelik Mühendisliği, EDA, Kategorik Veri Görselleştirme | `✅ Tamamlandı` |
| **3. Makine Öğrenmesi** | Regresyon, Sınıflandırma Modelleri, Model Değerlendirme | `✅ Tamamlandı` |

---

## 🛠 Kullanılan Teknolojiler & Kütüphaneler

* **Dil:** Python
* **Veri Analizi & İşleme:** Pandas, NumPy
* **Görselleştirme:** Matplotlib, Seaborn
* **Makine Öğrenmesi:** Scikit-Learn
